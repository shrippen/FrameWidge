FrameWidge

Native KDE Plasma 6 system tray widget for Framework Laptops. Fan curves, power profiles, battery limits, and live sensor telemetry — right from your panel.

This is a community Plasma widget built on top of ozturkkl/framework-control by Kemal Ozturk. It is not an official fork — it's an independent native KDE frontend that communicates with the existing framework-control REST API. The backend service is developed and maintained by the original author.
curl -fsSL https://raw.githubusercontent.com/shrippen/framework-control-plasmoid/main/install.sh | bash

Installs the framework-control backend service (requires sudo) and the Plasma widget via kpackagetool6. Then add FrameWidge from the widget picker.

GitHub Original Project

Fan Control

Auto, manual duty slider, and custom curve editor with drag-and-drop points. Hysteresis, rate limiting, per-fan overrides for Framework 16, and a calibration wizard for accurate RPM overlay.

Sensor Telemetry

Live temperature graphs with configurable history window, per-sensor selection, and color-coded legend. Data sourced from the backend's telemetry collector.

Power Profiles

Separate AC and battery profiles. EPP preference, CPU governor, frequency limits, TDP, and thermal controls — all capability-driven from the backend.

Battery Management

Live charge/discharge wattage, health percentage, cycle count, charge limit (25–100%), and charge rate limiting with optional SoC threshold. ETA to full or empty.

System Tray

Compact icon with configurable overlay (temperature, RPM, or SoC). Rich tooltip with live stats. Dims when the service is offline.

Smart Onboarding

When the backend is not installed, the widget shows a friendly setup guide with a copyable install command — no terminal hunting required.

Requirements

  • Framework Laptop — 13 or 16 (AMD or Intel)
  • KDE Plasma 6 — Wayland or X11
  • Linux with systemd — Arch, Fedora, NixOS, etc.
  • framework-control backend service — installed automatically by the install script, or via AUR / nixpkgs

How It Works

  • The framework-control service runs as a root systemd unit and communicates with the laptop's embedded controller via framework_tool.
  • It exposes a REST API on 127.0.0.1:30912 for reading sensors, setting fan modes, managing power profiles, and configuring battery limits.
  • This Plasma widget is a pure QML frontend that polls the API and sends config changes. No C++ compilation, no additional daemons.
  • All settings persist in /etc/framework-control/config.json and are applied at boot by the backend service.
